Plateforme de gestion intégrée pour résidences-services seniors — modèle Domitys

14 modules métier 13 phases comptables 5 assistants IA RGPD · FEC DGFIP
Document de présentation · Édition 2026 · Pilote vitrine

📌 En bref

Synd_Gest est une application web modulaire couvrant l'ensemble des opérations d'une résidence-services seniors :

  • Gestion administrative — résidences, lots, propriétaires, contrats de gestion
  • Gestion résidentielle — profils résidents seniors, occupations, services
  • Gestion opérationnelle — restauration, ménage, jardinage, maintenance, accueil, animations
  • Gestion comptable — 13 phases (compta unifiée, paie, TVA, exports FEC, IA assistants, rapprochement bancaire, quittances, impayés)
  • Conformité — RGPD, audit trail légal, FEC DGFIP, PCG art. 410-1
  • Espaces personnels — propriétaires, résidents, salariés (chacun voit ses propres données)

Stack technique

PHP 8.2 MariaDB 10.4 Bootstrap 5.3 Chart.js Leaflet TUI Calendar Claude AI

💰Comptabilité — Le module phare

Le plus riche — couvre tout le besoin comptable d'un parc de résidences.

Schéma unifié : 1 seule table ecritures_comptables agrège jardinage + ménage + restauration + maintenance + loyers + paie + admin + sinistres + hôtes + services. PCG simplifié : 44 comptes seedés.

1. Fondations : schéma unifié + Model + audit
2. Refonte modules → table unifiée
3. Dashboard central : 6 KPIs + Chart.js + comparaison N vs N-1
4. RH salariés : 8 conventions collectives FR + espace salarié
5. Bulletins de paie : taux 2026 réalistes + import auto heures
6. Exports comptables : FEC DGFIP officiel + CSV + Cegid
7. TVA CA3/CA12 : mapping CERFA 3310 lignes 01 à 32
8. IA Assistant Comptable (Claude Sonnet)
9. IA Assistant Paie (taux 2026 + conventions)
10. Bilan + SIG + Balance + GL + Exercices
11. Rapprochement bancaire : import CSV + matching auto
12. Audit trail métier : 18 actions tracées (RGPD + PCG)
13. Quittances + Gestion des impayés : génération mensuelle, escalade auto J+10, 3 niveaux de relance avec 9 templates FR

+ Polish navbar restructurée en 6 sections + bandeau "Actions à mener" + 8 cards "Accès rapides"

📨 Messagerie interne

  • Accessible à tous les utilisateurs authentifiés (sauf hôtes temporaires sans compte)

🔐 Sécurité & conformité

  • Sessions : timeout 30 min + avertissement 5 min avant
  • CSRF : token sur tous les POST + header X-CSRF-Token sur AJAX
  • Rate limiting : 200 req/min par IP
  • Logs sécurité fichier : 4 types (UNAUTHORIZED_ACCESS, FAILED_LOGIN, CSRF_VIOLATION, RATE_LIMIT_EXCEEDED)
  • Audit trail métier BDD : 18 actions comptables tracées avec ip + user_agent + JSON details
  • RGPD : masquage IBAN dans logs, accès données santé restreint, droit d'accès via espaces personnels
  • Headers HTTP sécurité : CSP, X-Frame-Options, X-Content-Type-Options…
